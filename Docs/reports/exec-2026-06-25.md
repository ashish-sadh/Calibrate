## What Shipped This Period
- **Coach bug fix: multi-supplement name extraction** — "I took my vitamin D and omega 3" now correctly identifies two separate supplements instead of treating the entire sentence as a single name. Root cause: mark_supplement tool received full input; implemented proper sentence tokenization and per-item parsing.
- **DriftChatSim macOS harness** — deterministic test runner driving the real chat pipeline over seeded database. Enables continuous validation of multi-turn conversations, tool routing, and edge cases without simulator friction.
- **Telemetry depth** — all chat turns (not just LLM turns) now logged to telemetry for failure-mode analysis. Enables future pattern discovery.
- **Voice UX polish** — auto-submit ~1.8s after user stops talking (tap-free voice). Bottom-nav shadow softening (pill + chat button visual refinement).
- **Development SOP canonical doc** — formalized workflow: make a change → test it → ship it. Single source of truth for local dev, CI, and TestFlight cadence.

## What's Working Well
1. **Chat reliability pipeline is hardening.** Per-tool gold sets shipping at 96%+ (build 300 baseline). Coach is the showstopper — focus on tool routing whiffs (supplement miss) is the right priority.
2. **Telemetry-driven iteration cycle is closing.** Raw text persistence + turn-level logging means every shipped failure becomes a test case and a prompt improvement.
3. **On-device architecture is solid.** Gemma 4 (2B, on-device default) + Nebius Coach backend (user opt-in) dual-model split is clean. Zero cloud data leakage on default path.

## Risks & Blockers
1. **#897 Coach multi-intent splitting not yet tested at scale.** One fix landed (vitamin D + omega 3), but edge cases (3+ supplements, food+supplement combos, quantified items) remain untested. Action: add to smoke test suite before marking done.
2. **Tier-3 LLM eval gate blocks feature merges.** Pre-TestFlight eval (~12 min per task) is necessary but slows iteration. Should run in parallel with senior/junior work, not sequentially.
3. **Telemetry volume outpacing analysis capacity.** Logging all turns is data-rich but human review bottleneck. Auto-clustering for pattern detection needed soon.

## Focus for Next Period
1. **Close P0 Coach bugs (#897, #896)** — supplement + food logging are the highest-sensitivity paths. Every fixed failure gets a Tier-0 test.
2. **Validate Nebius Coach backend reliability** — real users on real data. Response latency, error recovery, context window edge cases.
3. **Expand failing-queries.md repair** — historical date queries, non-weight goal setting, multi-intent chains. Driven by telemetry patterns, not speculation.
