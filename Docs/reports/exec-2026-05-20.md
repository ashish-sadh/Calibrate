# Drift Daily Briefing — May 20, 2026

TestFlight build 260 shipped with UI refinements and expanded food database; AI routing pipeline at 96% reliability across core tools.

## Product Snapshot
Drift is an AI-first health tracker — users type what they ate or did, AI handles logging, tracking, and insights. On-device, no cloud. Currently in closed beta on TestFlight.

## What Shipped This Period

## What's Working Well
- **Per-tool reliability at 96%** (48/50 gold set): log_food, log_weight, mark_supplement all at 100%; edit_meal and food_info at 90% after tuning
- **Dual-model strategy validated** — SmolLM (360M) as fallback for 6GB devices, Gemma 4 (2.9GB) for 8GB+; auto-detection working without user intervention
- **6-stage pipeline throughput stable** — instant rules handle 60-70% of queries, LLM classifier picks up typos/word-numbers, domain extraction handles complex multi-item meals

## Risks & Blockers
- **Food database ceiling at 6,000** enforced by FoodDBSizeTests; additions now require curation to avoid bloat (no bulk USDA SR Legacy imports)
- **llama.cpp Metal GPU unstable on A19 Pro** — backend falls back to CPU; no Metal path forward yet, limits on-device LLM perf ceiling
- **Voice input latency** — SpeechRecognizer sometimes hangs on intent classification; needs async refactor to avoid UI freeze on multi-turn queries
